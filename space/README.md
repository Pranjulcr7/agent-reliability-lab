# agent-reliability-lab: trace replay

**This Space replays recorded traces. It does not run a model, so no API key or GPU is needed.** All scenarios are
fictional. The bundled traces (`traces.json.gz`, seed 0 of the full benchmark) were produced by the
**scripted reference policy, not an LLM**. See the source repository for method, results and limitations:
https://github.com/Pranjulcr7/agent-reliability-lab
